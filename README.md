# Germany Study Guidance

Marketing website for a small business helping families and students plan higher education in Germany.

The whole project lives in [`web/`](./web). See [web/README.md](./web/README.md) for setup, scripts, structure, content editing and deployment, and [web/DEPLOYMENT_HANDOFF.md](./web/DEPLOYMENT_HANDOFF.md) for the Cloudflare Pages and Formspree handoff.

```bash
cd web
npm install
cp .env.example .env
npm run dev
```
